# 생활두뇌운동

## 서비스 소개

시니어가 일상 속 기억을 깨우고 자신에게 따뜻한 말을 건네도록 돕는 50분 강의 사이트입니다.  
강의 소개부터 15장의 슬라이드, 실습 자료까지 한곳에서 볼 수 있습니다.  
강사는 수업을 진행하고, 참가자는 휴대전화나 컴퓨터로 자료를 읽고 활용할 수 있습니다.

## 배포 주소

- [강의 소개와 수업 자료](https://bmct-self-praise-42.workspace-288742.chatgpt.site/)
- [강의 슬라이드 바로 보기](https://bmct-self-praise-42.workspace-288742.chatgpt.site/slides.html)

프로젝트에 설정된 공개 주소입니다. 내 컴퓨터에서 파일을 수정해도 공개 사이트가 자동으로 바뀌지는 않으며, 변경한 파일을 다시 올리는 배포 과정이 필요합니다.

## 주요 기능 5가지

1. **강의 안내**: 수업 대상, 일정, 50분 진행 순서와 강사 소개를 확인할 수 있습니다.
2. **15장 슬라이드**: 이전·다음 버튼으로 이동하고, 전체 보기에서 원하는 장을 선택할 수 있습니다. 휴대전화 화면에도 맞춰 표시됩니다.
3. **실습 자료 활용**: 문장을 복사하거나 전체 자료를 텍스트 파일로 내려받을 수 있습니다.
4. **수업 진행 도구**: 실습·휴식 타이머를 사용하고, 슬라이드를 PDF 파일로 저장할 수 있습니다.
5. **관리자 체험 화면**: 참가자 명단, 후기 공개 여부, 타이머와 진행 설정을 시험해 볼 수 있습니다. 실제 수강생 화면과 연결되지 않은 데모입니다.

## 사용 기술

| 기술 | 쉬운 설명 |
|---|---|
| HTML | 제목, 글, 버튼 등 화면의 내용을 구성합니다. |
| CSS | 색상, 글자 크기와 휴대전화용 배치를 정합니다. |
| JavaScript | 슬라이드 이동, 복사, 타이머 등 버튼의 동작을 처리합니다. |
| 브라우저 저장 공간 | 읽던 슬라이드 위치와 관리자 데모 데이터를 현재 브라우저에 저장합니다. 다른 기기와 공유되지는 않습니다. |
| Firebase Analytics | 랜딩과 슬라이드의 방문·이용 통계를 수집하도록 연결되어 있습니다. |
| Pretendard 글꼴 | 화면에 사용하는 한글 글꼴입니다. 인터넷에서 불러옵니다. |
| Open Graph·공유 카드 설정 | 링크를 공유할 때 제목, 설명과 대표 이미지가 표시되도록 합니다. |

추가 실습용으로 `firebase/` 폴더의 실시간 동기화 예제와 `stats.php`의 PHP 서버 예제가 포함되어 있습니다. 현재 공개용 `dist/` 폴더에는 이 예제들이 포함되어 있지 않습니다.

## 실행 방법

### 가장 쉬운 방법: 배포 주소 열기

위의 **강의 소개와 수업 자료** 링크를 크롬이나 엣지에서 열면 됩니다. 별도 설치나 회원가입 없이 기본 강의 자료를 볼 수 있습니다.

### 내 컴퓨터에서 보기

1. 프로젝트 폴더를 내려받고, 압축 파일이라면 먼저 압축을 풉니다.
2. `webslide-starter-kit` 폴더 안의 `index.html`을 두 번 클릭합니다.
3. 브라우저에서 **슬라이드 입장** 또는 **수업 자료**를 선택합니다.

기본 화면은 파일을 직접 열어서 볼 수 있습니다. 인터넷 글꼴·방문 통계는 연결 상태에 따라 동작하지 않을 수 있고, 복사는 브라우저 설정에 따라 제한될 수 있습니다. 복사 실패 안내가 나오면 문장을 직접 선택해 복사하면 됩니다.

### 로컬 서버로 보기: 선택 사항

파일을 직접 열었을 때 브라우저가 일부 동작을 제한한다면 아래 방법을 사용할 수 있습니다. Python이 설치된 컴퓨터에서만 실행하는 명령입니다.

1. `webslide-starter-kit` 폴더에서 터미널 또는 PowerShell을 엽니다.
2. 아래 명령을 입력합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

3. 브라우저에서 [내 컴퓨터의 사이트 열기](http://127.0.0.1:8000)를 선택합니다.
4. 사용을 마치면 터미널에서 `Ctrl+C`를 눌러 종료합니다.

별도의 패키지 설치나 빌드 명령은 필요하지 않습니다. 이 명령은 HTML 화면을 보여 주는 용도이며 PHP 서버 예제는 실행하지 않습니다.

## 사용 팁

| 하고 싶은 일 | 사용 방법 |
|---|---|
| 슬라이드 이동 | 화면 아래 이전·다음 버튼 또는 키보드 `←`, `→` |
| 전체 슬라이드 보기 | **전체 보기** 버튼 또는 `G` 키 |
| 전체 보기 닫기 | **닫기** 버튼 또는 `Esc` 키 |
| PDF 저장 | 컴퓨터에서 `P` 키 또는 **PDF 저장** 버튼을 누른 뒤, 인쇄 대상에서 **PDF로 저장** 선택 |
| 관리자 데모 열기 | `admin.html`을 열고 화면에 안내된 데모 비밀번호 `1234` 입력 |

관리자 화면의 변경은 현재 브라우저에만 저장됩니다. 진행 잠금이나 후기 공개 설정을 바꿔도 실제 슬라이드와 공개 사이트에는 반영되지 않습니다. 데모 비밀번호는 실제 운영용 보안 기능이 아닙니다.

## 파일 안내

| 파일·폴더 | 역할 |
|---|---|
| `index.html` | 강의 소개와 수업 자료 |
| `slides.html` | 15장 강의 슬라이드 |
| `admin.html` | 관리자 체험 화면 |
| `assets/` | 수업 이미지와 1200×630 공유 이미지 |
| `dist/` | 공개 사이트에 올리는 파일 모음 |
| `firebase/` | 별도 설정이 필요한 실시간 동기화 예제 |
| `stats.php` | PHP 호스팅에서 사용하는 서버 예제 |
| `.env.example` | 환경변수 이름을 안내하는 예시 파일 |

현재 배포 설정은 `dist/` 폴더를 사용합니다. 원본 HTML이나 이미지를 수정했다면 `dist/`의 해당 파일에도 변경 내용을 반영한 뒤 배포해야 합니다.

PHP 서버 예제를 사용할 때는 호스팅의 환경변수 설정에 `ADMIN_PASSWORD`를 등록해야 합니다. 미설정 상태에서는 관리자 기능이 잠깁니다. `.env` 파일을 만드는 것만으로 PHP가 값을 자동으로 읽지는 않습니다. 실제 비밀번호는 코드에 적지 않으며, `.env`와 `.env.*`는 Git 저장 대상에서 제외되고 값이 없는 `.env.example`만 예외로 관리됩니다.
